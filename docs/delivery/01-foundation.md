# 阶段 01 · 工程基础与合成数据

状态 · 已验收

## 进入条件

已确认规格、PRD 和接口设计合同。

## 交付内容

- 建立 Python 3.12 项目和锁文件、原生启动和配置示例。验证原生 MySQL、应用回环端口、独立数据目录及连接。
- 创建 MySQL 迁移及合成数据生成器。实现固定种子、固定观测时间、业务事件关联、两租户样例、政策语料及改进/验证/最终集清单。Redis 和 Milvus 随阶段 04 的检索和记忆功能接入。
- 提供应用探针、受回环配置控制的演示身份、基础会话接口和幂等写入。播种命令支持新实例及重复初始化。

## 验收与交接

- 执行 AT-01，保存 原生进程配置与启动状态、重复迁移与播种结果、数据集版本和哈希。
- 复核同一幂等键只建一个会话，其他租户不能读取。最终集标签目录仅供最终评测命令加载。

交给阶段 02 的版本化业务快照、租户和角色模型、运行环境、数据播种入口和接口配置。
