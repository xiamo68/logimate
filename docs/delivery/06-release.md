## 真实 DeepSeek 验收

在 Windows 原生 MySQL、独立 MCP HTTP 服务及 Milvus Lite 上跑通 `deepseek-flash` 售后问答并核对有效政策引用。基础候选的验证错误由 2 降至 1。元层候选对比初始活动版本由 2 降至 0，同起点技能对照由 1 降至 0。首次元层响应缺少约定字段，收紧成 JSON 二选一并加入有限格式重试后通过。回归测试含真实 Redis 与 Milvus 集成，共 16 项通过。

| 冻结集场景 | 实测 |
| --- | --- |
| 物流三组，每组 100 例 | 40% → 36% → 30%。两组候选均由真实模型提案，最终分类用同一规则执行器离线计算 |
| 售后检索 | BM25 Recall@5 45/48，混合 48/48。另有 12 道无适用条款问题，政策语料是 4 个合成片段 |
| 售后问答 | 56/60，准确率 93.33%，可回答覆盖率 44/48 |
| 事实校验对照 | 两组均未观测到无依据引用。自由判断组 60/60，证据校验组 57/60，原因是校验组额外拒答 3 道可回答问题 |

成功批次中，RAG 请求 60 次，事实对照请求 120 次，生成候选请求 3 次，在线售后冒烟请求 2 次，物流回放无外部调用。RAG 与事实对照合计记录输入 75,471 token、输出 9,445 token，其中缓存命中输入 12,800 token。首次诊断尝试另计。真实评测在修复分支工作区执行，归档保留原始 `code_ref` 和 `-dirty` 标记，元层修复见 `30babad`。

逐案例归档位于[评测结果](../qa/results/README.md)。结论限于合成数据与结构化政策动作评分。简历可写实测的物流改善，售后准确率与幻觉对比均使用本页数值。
